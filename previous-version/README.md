# Previous BoulderApp version

This is a byte-for-byte copy of the last vanilla app version before the React migration. It was recovered from the workspace's local Git object database and includes its matching `index.html`, `app.js`, `styles.css`, `wall-illustration.svg`, and `DESIGN.md`.

From the project root, run `npm run dev`, then open `/previous-version/index.html`. Use `/compare.html` to switch between this version and the React app at the same viewport size.
